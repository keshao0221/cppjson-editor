# 学生成绩管理系统

## 1. 数据结构：链表

使用单向链表存储学生信息，每个结点包含：
- 学生编号 (int)
- 姓名 (string)
- 班级 (string)
- 数学成绩 (string)
- 语文成绩 (string)
- 英语成绩 (string)
- 专业成绩 (string)
- 指向下一结点的指针

## 2. 实现功能

### 2.1 增删改查
| 功能 | 说明 |
|-----|------|
| 添加学生 | 在链表尾部添加新学生 |
| 插入学生 | 在指定位置插入学生 |
| 删除学生 | 根据编号删除学生 |
| 修改学生信息 | 修改姓名、班级、成绩 |
| 查找学生 | 按编号或姓名查找 |

### 2.2 持久化存储
| 操作 | 说明 |
|-----|------|
| 保存到文件 | 二进制格式存储 (`data.nd`) |
| 从文件加载 | 启动时自动恢复数据 |

### 2.3 成绩管理
| 功能 | 说明 |
|-----|------|
| 批量录入成绩 | 指定学号范围和科目批量录入 |
| 成绩验证 | 校验分数范围 (0-100) |
| 修改成绩 | 单独修改某学生某科目成绩 |

### 2.4 统计分析
| 功能 | 说明 |
|-----|------|
| 院系排名 | 计算学生在全院系的排名 |
| 班级排名 | 计算学生在班级内的排名 |
| 不及格统计 | 显示两门以上不及格的学生 |

### 2.5 数据导出
| 功能 | 说明 |
|-----|------|
| 导出文本文件 | 导出所有学生信息到 `StudentInformation.txt` |

### 2.6 权限管理
| 角色 | 权限 |
|-----|------|
| 学生 | 查看信息、查找、导出、查看排名 |
| 教师 | 学生权限 + 录入成绩、修改成绩 |
| 管理员 | 所有权限 + 添加/删除学生 |

## 3. 用户角色

### 3.1 学生
- 查看所有学生信息
- 按姓名查找学生
- 查看不及格学生名单
- 导出数据到文件
- 查看班级单科排名

### 3.2 教师
- 所有学生权限
- 批量录入单科成绩
- 修改学生成绩

### 3.3 管理员
- 所有教师权限
- 添加学生
- 删除学生
- 修改学生基本信息
- 插入学生

## 4. 业务规则

### 4.1 排名计算
- 支持按数学、语文、英语、专业、总分排名
- 采用顺序排名（相同分数不同名次）

### 4.2 成绩验证
- 分数范围：0-100
- 支持小数成绩

## 5. 菜单结构

```
主菜单
├── A: 学生登录
│   ├── A: 输出所有学生信息
│   ├── B: 查找学生
│   ├── C: 输出不及格学生
│   ├── D: 导出文件
│   ├── E: 班级单科排名
│   └── F: 切换身份
└── B: 管理员登录（需密码）
    ├── A: 输出所有学生信息
    ├── B: 查找学生
    ├── C: 删除学生
    ├── D: 添加学生
    ├── E: 修改学生信息
    ├── F: 输出不及格学生
    ├── G: 批量录入成绩
    ├── H: 导出文件
    ├── I: 班级单科排名
    └── J: 插入学生
```
